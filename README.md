# YourMettings

Backend обработки текста и аудиозаписей совещаний: FastAPI, PostgreSQL, GigaAM и Ollama/Qwen. Мобильный клиент находится в `mobile/` и разрабатывается отдельно.

Backend: `backend/`. Документы и контракт API: `docs/`.

Разработка backend ведётся в ветке `backend`; автоматического merge в `main` нет.

Реализованы ASR, папки и summary, системные/пользовательские шаблоны, предпросмотр и выбор вариантов результата, email-авторизация и отдельный демонстрационный доступ через HTTPS-шлюз. Почтовая доставка и доступность demo имеют ограничения, указанные в отчётах. Sharing остаётся вне реализованного сценария.

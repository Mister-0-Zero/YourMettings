# YourMettings

Локальный backend обработки готовых транскриптов совещаний: FastAPI, PostgreSQL, Ollama/Qwen. Мобильный клиент находится в `mobile/` и разрабатывается отдельно.

Backend: `backend/`. Документы и контракт API: `docs/`.

Разработка backend ведётся в ветке `backend`; автоматического merge в `main` нет.

Текущий MVP: один тестовый пользователь, готовый текст, один системный шаблон, папки и персональные summary. ASR, регистрация и sharing отложены.

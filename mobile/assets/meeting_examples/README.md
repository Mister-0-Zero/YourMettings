# Вымышленные встречи для тестирования шаблонов

Три полноразмерных учебных диалога, без пользовательских данных. Названия, размеры
в словах и символах, пути и SHA-256 находятся в catalog.json. Тексты входят в APK;
загрузка из сети и генерация на устройстве не нужны.

Исходные сценарии находятся в tool/build_meeting_examples.py. Они описывают
факты, альтернативы, принятые решения, владельцев, сроки и открытые вопросы.
Служебные реплики ведущих намеренно повторяются; это постановочные примеры.
Сборка выполняется командой python tool/build_meeting_examples.py из mobile.
Файлы UTF-8 с LF. Изменение текста требует пересборки каталога.

Критерии проверки полного входа:

- Планёрка: в конце предварительное 3 ноября заменено на 5 ноября. Пилот
  ограничен двадцатью клиентами; широкий запуск не утверждён. Павел отвечает
  за подготовку до 30 октября; доступ и откат должны быть проверены.
- Отчёт руководителю: итоговый предел проверки — 90 000 рублей, ранние
  120 000 заменены. 225 000 на широкий запуск не разрешены. Максим уточняет
  план к 3 ноября; постоянный перевод и найм не согласованы.
- Вовлечённость: выбраны три эксперимента, остальные идеи не стали поручениями.
  Окончательный запуск 12 ноября, наблюдение до 3 декабря, разбор 7 декабря.
  Общий предел — 45 000 рублей вместо 60 000. Участие добровольное.

Слова считаются регулярным выражением из генератора, а не делением числа
символов на среднюю длину слова. Данные загрузчика проверяются на целостность.
Старый API теста ограничен 12 000 символами — эти файлы в него не отправляются
и не обрезаются. Запуск полных примеров подключается по обновлённому backend
контракту; наличие ассетов само по себе не увеличивает окно модели.

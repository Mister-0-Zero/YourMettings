## Реализовано

- «Рабочее пространство → Шаблоны»: каталог с группами «Готовые шаблоны» и «Мои шаблоны». Все семь встроенных определений приходят с сервера.
- Просмотр структуры и инструкций; системные шаблоны доступны для копирования. Редактирование и удаление доступны только пользовательским.
- Создание, копирование, полная замена, удаление с подтверждением. После операции каталог обновляется.
- Конструктор: название, описание, строгий/гибкий режим, общие инструкции, обычные разделы и повторяемые тематические блоки. Вложенные разделы редактируются на отдельном экране; порядок меняется стрелками. Идентификаторы разделов сохраняются, позиции пересчитываются на каждом уровне.
- Защита несохранённых правок при выходе, сохранение с ошибкой оставляет редактор открытым.
- Единый выбор шаблона перед Qwen для текста, аудио после GigaAM и повторной обработки по существующему transcript ID. По умолчанию используется универсальный шаблон.
- Выбор сохраняется в текстовом/аудиочерновике и принятой операции. Неопределённый исход отправки повторяется с прежним ключом и точными параметрами; исчезнувший из каталога шаблон не подменяется незаметно.
- Тестирование текущего, в том числе несохранённого шаблона: отдельный preview API, автоматический polling, без встречи и папок. Текст, детализация и принятый preview сохраняются в памяти на время жизни редактора; возврат к инструкциям не создаёт второй тест. После изменения шаблона старый результат помечается как результат предыдущего теста.
- Общий Markdown-просмотр сохранённого summary, результата обработки и preview: сворачиваемое оглавление, явные уровни заголовков, переходы по `#ym-h-N`.
- Цели оглавления назначаются реальным заголовкам по серверному `line_index`; совпадения названий, кириллица, fenced code, цитаты и setext-заголовки не смещают цели. Подписи оглавления декодируют Markdown-экранирование после редактирования. HTML-якоря не используются.
- Дата и участники отображаются приглушённо только в явно подписанных соответствующих полях самого summary. Flutter не читает транскрипт для извлечения этих сведений и не подставляет дату создания вместо даты встречи.
- «Профиль → Оформление»: отдельный цвет документов (оранжевый, синий, зелёный, фиолетовый, розовый) и переключатель окраски жирного текста, включённый по умолчанию. Старые настройки мигрируют с безопасными значениями по умолчанию. Оформление не записывается в Markdown и не требует Qwen.
- Новые экраны учитывают системную панель Android и клавиатуру.

## Подключённые API

| Сценарий | Маршруты |
|---|---|
| Каталог, просмотр | `GET /summary-templates`, `GET /summary-templates/{id}` |
| Конструктор | `POST /summary-templates`, `PUT /summary-templates/{id}` |
| Копирование, удаление | `POST /summary-templates/{id}/copy`, `DELETE /summary-templates/{id}` |
| Несохранённый тест | `POST /template-previews`, `GET /template-previews/{id}` |
| Текст | Прежний `POST /transcripts/process` с `template_id` |
| Аудио | Прежний `POST /audio-sessions/{id}/confirm` с `template_id`, подтверждением и SHA проверенного текста |
| Явный повтор Qwen | Прежний `POST /transcripts/{id}/process` |
| Результат и редактор | Прежние processing GET, summary GET/PATCH с актуальной `navigation` |

Новых backend endpoints не добавлялось. Для preview нет автоматического повторного POST; повторное нажатие заблокировано до завершения принятия/обработки. Временный 404 сохраняет текст теста и предлагает явный новый запуск.

## Найденная причина защищённых списков

Реальный краткий ответ Qwen содержал обычный вложенный список с пустой строкой между верхними пунктами. Markdown AST для такого loose list добавляет оболочку `p` внутри `li`; Quill экспортирует эквивалентный tight list без этой оболочки. Строгое сравнение ошибочно считало это потерей структуры и защищало блок.

Сравнение теперь нормализует только единственный текстовый абзац пункта, после которого могут идти вложенные списки. Текст, inline-стили и иерархия списков проверяются по-прежнему. Несколько самостоятельных абзацев не объединяются: отдельный отрицательный тест подтверждает запрет такой потери. В фикстурах сохранены два настоящих результата Qwen; оба проходят редактирование и повторное открытие. Пустые строки и экранирование пунктуации при сохранении могут нормализоваться, содержимое и вложенность сохраняются.

## Границы

- Существующий редактор по-прежнему сохраняет неподдерживаемые сложные конструкции (например, HTML, таблицы, определения ссылок и многоабзацные пункты списков) неизменяемыми вставками. Это безопасный прежний режим; обычные текст, заголовки, выделение, ссылки и проверенные вложенные задачи редактируются непосредственно. Новые цветовые HTML-конструкции не создаются.
- Preview временный: сервер хранит его в памяти ограниченное время; приложение хранит тестовую сессию только пока открыт редактор. Это не библиотека встреч и не постоянное сохранение тестового текста.
- Оглавление использует серверную navigation для ATX-заголовков. Документы без таких заголовков могут не иметь navigation по контракту.
- Проверена Android-сборка на HONOR. macOS/Xcode недоступны; сборка и тестирование на iPhone не выполнялись.
- Эта APK настроена на USB-адрес `http://127.0.0.1:8000/api/v1`; для её работы на телефоне требуется ADB reverse. LAN с VPN отдельно не заявляется как проверенный.

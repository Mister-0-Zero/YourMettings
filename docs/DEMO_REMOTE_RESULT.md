## Реальный аудиотест через публичный HTTPS

Использована локально синтезированная русская речь Microsoft Irina без личных данных. Из файла взяты **180 секунд**, два WAV/PCM фрагмента по 90 секунд и **2 880 078 байт** каждый. Большие файлы намеренно проверяют передачу через прокси, а не рекомендуемый формат мобильной записи.

Первый запрос столкнулся с 504 через 132.58 с при прежнем proxy timeout. Фрагмент сохранился в БД. Повтор с прежней сессией/номером/байтами после увеличения timeout вернул **200 за 152.62 с** с тем же chunk ID. Данные не удалялись и новая встреча для обхода ошибки не создавалась.

Повторный полный прогон существующего `tests/e2e_audio_real.py` через HTTPS:

- Оба фрагмента приняты; повтор каждого вернул тот же объект, дублей нет.
- Complete → GigaAM v3 `v3_e2e_rnnt` → ready_for_review; получено **2195 символов** транскрипта, Qwen до confirm не запускался.
- Проверочный PATCH текста → confirm 202 → повтор confirm 200 → Qwen `qwen3.8:27b` → ready и summary **3862 символа**. В БД **одна попытка Qwen**.
- ASR worker generation не изменилась; после распознавания бинарные chunk payload очищены по прежним правилам.
- Собственная диагностическая встреча удалена через API; SHA-256 исходных текстов и summary всех существовавших до теста записей остались прежними.
- Весь прогон **652.687 с**; метрика `asr_elapsed_seconds=604.265` включает четыре долгие загрузки/повтора, complete и ожидание ASR, это **не чистое время работы модели**.

## Ограничения и следующие действия Flutter

На реальном SSH/VPN-маршруте наблюдались TCP retransmissions и низкая скорость: 2.88 MB WAV передавались около 153 с. Увеличение таймаута обеспечило завершение запроса, улучшение скорости от IPQoS не доказано. Предпочтителен AAC/M4A, разумны фрагменты 30–60 с, если совместимо с мобильной реализацией. Upload timeout 300–360 с, сохранение файлов до подтверждения, повторы с теми же IDs и байтами обязательны. Proxy response-header timeout 5 минут, body/write до 10 минут.

Flutter должен дать сменить URL без пересборки и ввести ключ скрытым полем, хранить его защищённо на origin и маскировать в логах. Точные правила/ошибки/USB переключение: [FLUTTER_DEMO_HANDOFF.md](FLUTTER_DEMO_HANDOFF.md), [API_CONTRACT.md](API_CONTRACT.md), экспорт [openapi.json](openapi.json).

**Сотовый тест с телефона пока не выполнен.** Серверный сквозной тест прошёл через публичный IP/HTTPS при включённом AmneziaVPN; это не подтверждение поведения конкретного Android/iOS приложения. После внедрения заголовка/настроек Flutter-агенту нужно проверить реальную запись из мобильной сети.

Домашние сервисы и туннель оставлены работающими. Caddy стартует после reboot VPS; Windows-туннель — после входа текущего пользователя. Домашний ПК должен не спать, backend запускается существующим ярлыком. Демонстрационный доступ общий: только вымышленные данные. Запуск/восстановление, отзыв ключа и закрытие публичного доступа: [DEMO_REMOTE_SETUP.md](DEMO_REMOTE_SETUP.md).

## Реализация

- Экран теста предлагает три полных локальных вымышленных транскрипта или свой
  текст. Собственный ввод сохраняется при переключении на готовый пример.
  Полный пример можно прочитать до запуска.
- Старый лимит 12000 заменён одновременными ограничениями 15000 слов,
  200000 символов и 400000 UTF-8 байт. Вставка не обрезается.
- Preview отправляет Idempotency-Key, сохраняет точный незавершённый запрос и
  ID. Возврат к тесту доступен из каталога шаблонов после перезапуска приложения.
  GET 404/410 оставляет исходный текст доступным для явного нового теста.
- Новые текстовые встречи и проверенное аудио используют summary-selections,
  не прежние однократные process/confirm с немедленным сохранением.
- Сохранённая встреча открывает выбор через меню «Изменить шаблон» по summary_id.
  До выбора доступен её исходный сохранённый вариант.
- Кнопка создания варианта запускает обработку по выбранному шаблону.
  Стрелки переключают полученные результаты; навигация не делает POST.
  Название выбранного шаблона синхронизируется с открытым кандидатом.
- «Готово» принимает только активный ready-кандидат. Исходная summary_version
  не заменяется при конфликте. После принятия читается актуальное summary,
  поскольку квитанция повторного accept может предшествовать поздней правке.
- Отдельное generation-operations.json хранит незавершённые checkpoints:
  ключ открытия, точный pending body, session/transcript IDs, версию,
  candidate IDs и зафиксированное намерение принятия либо отмены.
  Запись на диск предшествует изменяющему HTTP-запросу.
- Потеря ответа accept фиксирует конкретного кандидата до выяснения результата.
  Черновик очищается после подтверждённого принятия и локального завершения.
  Отмена/истечение сохраняет исходный редактируемый черновик.
- Аудио сохраняет проверку стыков и SHA-256 исправленного текста. Выход через
  сохранение черновика освобождает диктофон, сохраняя выбор для продолжения.
  Удаление аудиовстречи сначала отменяет незавершённый выбор.
- Прежний recovery version=1 продолжает читать и отслеживать старые операции.
  Новой локальной библиотеки готовых встреч нет.

Новые проверки покрывают потерянные ответы открытия/кандидата/принятия/отмены,
восстановление с диска, неизменность ключей и тела, отсутствие HTTP при ошибке
checkpoint, конфликт версии, A→B→A без запросов, полный исходный asset,
соответствие выбранного шаблона активному кандидату после восстановления,
подготовку аудио без ASR/confirm, передачу аудиочерновика и безопасное удаление
при другой активной записи.

Интерфейсные проверки: текстовый черновик сохраняется до «Готово», затем
открывается форматированный итог; принятие варианта сохранённой встречи
немедленно обновляет просмотр; отмена перечитывает внешнюю ручную правку.

Реальный Markdown длинного preview сохранён в
mobile/test/fixtures/template_long_preview_real_2026-10-24.md.
Проверен цикл Markdown → визуальный документ → изменение → экспорт →
повторное открытие, без защищённых блоков; сравниваются текст и структура
заголовков, выделений, списков и ссылок.

   source_words=6357 (split), source_bytes=88702, strategy=direct.

   «Продолжить тест шаблона» восстановил прежний preview ID без нового POST.
   Готовый результат 9292 символа отображается с форматированием; в нём есть

   универсальный и краткий. До «Готово» в тестовой папке 0 summary.
   Переходы назад/вперёд сохранили те же два candidate ID.
4. После обновления APK/перезапуска восстановился второй вариант с правильным
   шаблоном. «Готово» создал ровно одно summary с его template_snapshot,
   открыл форматированный просмотр и очистил только принятый текстовый draft.
5. У сохранённой встречи проверены смена шаблона, возврат к исходному варианту,
   повторный переход и принятие нового результата. До принятия исходное
   содержимое/версия не менялись. После принятия сохранены summary ID,
   transcript ID и папка; версия изменилась.

   выражение присваивания Future мешало обновлению просмотра после принятия.
   Регрессионный тест сначала падал, затем прошёл. Исправление повторно проверено
   на телефоне: новый текст появился сразу после «Готово». Такой же возврат
   Future устранён в затронутых повторных загрузках.

   и preview удалены; GET preview возвращает 410. Единственный оставшийся

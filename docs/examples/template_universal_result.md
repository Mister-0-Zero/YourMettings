## Тематический разбор

### Выпуск API версии 2.4

#### Название темы

Выпуск API версии 2.4

#### Суть обсуждения

Цель — подготовить версию 2.4 без потери совместимости. Миграция индекса PostgreSQL готова, однако тест отката ещё не выполнен. Борис предложил выпустить версию в тот же день; Анна отклонила предложение и зафиксировала дату выпуска 30 октября при условии успешного теста отката. Отдельно обсуждён лимит запросов: 120 в минуту подтверждён, вариант 200 оставлен без решения.

#### Ключевые моменты и аргументы

- Миграция индекса PostgreSQL завершена, тест отката не выполнен.
- Борис предложил немедленный выпуск; Анна настаивала на выполнении теста отката до релиза.
- Лимит 120 запросов/минуту подтверждён как текущий.
- Вариант 200 запросов/минуту рассматривался как возможное будущее расширение, решение не принято.

#### Принятые решения

- Выпуск версии 2.4 — **30 октября**, только после успешного теста отката.
- Лимит запросов зафиксирован на уровне **120 в минуту**.

#### Задачи

- Провести тест отката миграции индекса PostgreSQL. **Ответственный:** Борис. **Срок:** 28 октября.

#### Ответственные

Борис — тест отката.

#### Сроки

- **28 октября** — тест отката (Борис).
- **30 октября** — выпуск версии 2.4.

#### Открытые вопросы

Вопрос о повышении лимита до 200 запросов/минуту остаётся открытым; решение не принято.

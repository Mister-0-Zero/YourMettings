### Выпуск API версии 2.4

#### Название темы

Выпуск API версии 2.4

#### Суть обсуждения

Цель — подготовить версию 2.4 без потери совместимости. Миграция индекса PostgreSQL готова, однако тест отката на момент обсуждения не выполнен. Борис предложил выпустить версию в тот же день; Анна отклонила предложение и зафиксировала условие: выпуск только после успешного теста отката. В заключительном уточнении дата выпуска перенесена с 30 октября на 3 ноября, при этом срок теста отката (28 октября) сохранён.

#### Ключевые моменты и аргументы

- Тест отката включает: проверку схемы до и после миграции, сравнение количества записей, проверку доступности индекса.
- Лимит запросов: 120 в минуту — принято. Вариант 200 в минуту — только гипотетическое будущее повышение, согласования нет.
- Немедленный выпуск (предложение Бориса) отклонён; принятым условием остаётся успешная проверка отката.

#### Принятые решения

- Выпуск API версии 2.4 — **3 ноября** (перенесён с 30 октября).
- Условие выпуска: успешный тест отката.
- Лимит запросов зафиксирован на уровне **120 в минуту**.

#### Задачи

- Провести тест отката миграции индекса PostgreSQL (проверка схемы, количества записей, доступности индекса).
  **Ответственный:** Борис
  **Срок:** 28 октября

#### Ответственные

Борис — тест отката

#### Сроки

- Тест отката: **28 октября**
- Выпуск версии 2.4: **3 ноября**

#### Открытые вопросы

Повышение лимита до 200 запросов в минуту — решение не принято, вопрос остаётся открытым.

### Архив и перенос файлов

#### Название темы

Архив и перенос файлов

#### Суть обсуждения

Основной риск — потеря файлов при переносе. Ирина предложила удалять старые файлы через неделю после переноса; предложение не принято. Согласован порядок: сначала резервная копия, затем — при необходимости — удаление. План резервирования должен описывать проверку копии и возможность восстановления. Пока проверка не завершена, исходные файлы сохраняются. Срок самого переноса на момент встречи не определён.

#### Ключевые моменты и аргументы

- Риск потери файлов при переносе — ключевой аргумент за осторожность.
- Предложение об автоматическом удалении через неделю (Ирина) — **не утверждено**.
- План должен включать: проверку копии, возможность восстановления.
- До завершения проверки исходные файлы не удаляются.

#### Принятые решения

- Перед переносом выполняется **резервная копия**.
- Удаление исходных файлов через неделю **не утверждено**.
- Пока проверка копии не завершена, исходные файлы **сохраняются**.

#### Задачи

- Подготовить план резервирования (описание проверки копии и возможности восстановления).
  **Ответственный:** Борис
  **Срок:** 31 октября

#### Ответственные

Борис — план резервирования

#### Сроки

План резервирования: **31 октября**
Срок переноса: **не определён**

#### Открытые вопросы

- Срок переноса файлов не определён.
- Вопрос удаления исходных файлов после переноса остаётся открытым (предложение не утверждено).

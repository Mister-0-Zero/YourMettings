# Копирование итога встречи: 22 октября 2026

Реализовано только согласованное действие «Копировать итог». Шаблоны и поиск этой задачей не менялись. Ветка mobile, backend и API-контракт не затронуты.

## Поведение

В просмотре сохранённой встречи действие находится в меню с тремя точками. На экране готового результата после генерации доступна кнопка «Копировать итог». В редакторе и до получения результата действие не показывается.

Оба входа используют один helper mobile/lib/services/summary_clipboard.dart. В буфер помещаются подтверждённое название, два перевода строки и полный Markdown summary. Разметка, ссылки, таблицы и пробелы не преобразуются; исходный транскрипт не включается. Используется актуальная загруженная/подтверждённая версия, а не переданный при создании экрана старый объект и не конвертация редактора. Новых запросов к API или локальных копий файлов действие не создаёт.

После успешного ответа платформы показывается «Итог встречи скопирован». При ошибке — «Не удалось скопировать итог. Повторите попытку». Ошибка не меняет документ. Если экран уже закрыт, сообщение не обращается к уничтоженному контексту.

## Реализовано

- Пояснения по нажатию для строгой/гибкой структуры, разделов для каждой темы,
  обязательных разделов и пожеланий к итогу.
- Разделение копирования и редактирования: копия создаётся без открытия редактора,
  карандаш открывает редактирование, галочка сохраняет с уведомлением.
- Удаление собственного шаблона — внизу просмотра, с подтверждением.
- При выборе шаблона показываются названия, без описаний.
- В поле теста превышение текущего лимита API не обрезает вставленный текст.
  Запрос отклоняется локально с пояснением; весь текст остаётся в поле.
- Результат прошлого теста отличается от текущего ввода не только по шаблону,
  но и по тексту/детализации. Изменение этих параметров не запускает LLM само.
- Три полных вымышленных встречи включены в APK как статические ассеты:
  планёрка — 6325 слов / 48163 символа; отчёт руководителю — 6453 / 49521;
  вовлечённость — 6581 / 50263. Каталог содержит SHA-256. Загрузчик отвергает
  повреждённый или неполный файл. Реплики собраны из авторских сценариев;
  служебные формулировки ведущих повторяются, это постановочные примеры.

## HONOR 400, Android 16

Установлена USB-сборка через обновление без очистки данных. Адрес
http://127.0.0.1:8000/api/v1 работает через ADB reverse. Для LAN этот APK
требует другого адреса сервера; настройки сети и VPN не менялись.

В реальном приложении проверено:

1. Копирование готового краткого шаблона, появление уведомления и новой записи
   каталога. Пользователь остаётся в просмотре шаблона.
2. Карандаш открывает редактор нашей копии. При открытой клавиатуре изменено
   название; галочка сохраняет, возвращает к просмотру и показывает уведомление.
   Отдельный GET API подтвердил изменённое имя.
3. Пояснение о структуре открывается нажатием и читается в светлой и тёмной теме.
4. Удаление находится внизу, открывает подтверждение и удаляет только нашу копию.
   После проверки набор ID шаблонов полностью совпал с исходным, включая
   пользовательский шаблон.
5. Исходная тема возвращена. Контрольные суммы audio-drafts.json,
   meeting-recovery.json и appearance.json совпали до и после проверки.
